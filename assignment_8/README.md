\# Assignment 8 – Image Generator CLI



A Python command-line application for generating images with the

OpenAI Image API and the gpt-image-2 model.



\## Features



\- validates command-line parameters

\- accepts a text prompt

\- supports configurable aspect ratios

\- generates 1–10 images

\- supports low, medium and high quality

\- handles API and network errors

\- supports Base64 image data and temporary image URLs

\- saves images with safe and unique filenames

\- prints the paths of all saved images
